name: Original-content demo approval
description: User approval to show the connected agent's original content in a frozen sample.
---

The user asked to offer the currently connected agent as a sample for demo
visitors who do not have their own agent. When offered an anonymized snapshot,
an original snapshot, or configuration only, they chose **“Share original
snapshot.”**

**Why:** The user approved original call transcripts and evaluation details
after being told these could be visible to anyone opening the sample.

**How to apply:** Keep that intentional sample disclosure distinct from the
account-private connection. The approval is for the sample content, not for
sharing credentials, granting visitors access to the owner's workspace, or
automatically sharing other private connections.
