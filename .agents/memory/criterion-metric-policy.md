name: Criterion-level metrics instead of binary pass rates
description: User wants evaluation criteria and per-call failing criteria, not an overall binary score.
---

“Let's not show pass rate because you are keeping it binary, and I don't want
it to be binary.” Show evaluation criteria and failed criteria, including how
many criteria per call are failing, instead of headline pass rates and
failed-call totals.

**Why:** The user explicitly rejected reducing the agent's performance to
binary call-level outcomes.

**How to apply:** Use criterion-level evidence as the primary performance
view. Keep unknown/missing analyses distinct, and preserve actual numeric
provider scores rather than converting them to a binary aggregate.
